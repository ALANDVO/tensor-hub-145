## Overview

Tensor Hub provides a collection of tools and demos for learning and building AI/ML models. This repository includes a logistic regression demo with threshold tuning, demonstrating safe metric computation even for edge cases such as all-zero predictions.

## Features

- Logistic Regression demo with synthetic dataset
- Threshold tuning across thresholds
- Robust metrics calculation handling all-zero/all-one predictions (bug fix)
- Simple API for extension

## Usage

Run the demo:

```bash
python -m src.tensorhub.demo_logreg
```
