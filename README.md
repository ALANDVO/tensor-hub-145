# Tensor Hub - AI Engineering Platform — Alan Vo

Current version: `1.3.0`.

> Work in progress. This checkpoint may be incomplete or fail tests. See PLAN.md and STATUS.md before use.


Tensor Hub is a platform for learning AI engineering concepts and building practical AI applications. This repository contains educational materials for understanding and implementing various AI and machine learning concepts.

## Overview

This repository follows an incremental development approach, where each phase builds upon the previous ones to create a comprehensive understanding of AI engineering. The materials cover a wide range of topics from basic machine learning fundamentals to advanced AI systems.
